1 · k 是间隔，不是某一个时刻

例如第 10 天：k = 1 就比较 X₁₀ 与 X₉，k = 2 比较 X₁₀ 与 X₈。换成第 20 天，同样的间隔就比较 X₂₀ 与 X₁₉、X₂₀ 与 X₁₈。对平稳过程，同一间隔对应同一个总体相关系数。

两期经常一起高于各自均值、或一起低于均值，相关倾向为正；经常一高一低，相关倾向为负。相关为零只表示没有线性相关，一般不等于独立。ρ = 0.6 也不是“有 60% 的概率同向”。

2 · 一根柱子，只回答一个间隔的问题

这里“衰减”指绝对值逐渐趋近 0。φ < 0 时正负交替；φ ≠ 0 时，通常不会在某一阶后突然全部变成 0，这叫拖尾，不是每一阶都很大。

例题：ACF 与自协方差不能混用

因果平稳模型 Xₜ = 2 − 0.5Xₜ₋₁ + εₜ，创新方差为 3。求均值、过程方差、第 2 阶自相关及自协方差。

ρ(2) = 0.25 没有单位；γ(2) = 1 带有原变量单位的平方。常数 c 改变均值，创新方差改变协方差的尺度；但在这些条件下，它们都不改变 AR(1) 的 ACF 形状。

完整例题：两个方向都算一遍

以下例题固定为 Xₜ = 0.5Xₜ₋₁ + 0.2Xₜ₋₂ + εₜ，创新方差为 1。它与上方可调参数的演示分开，不随滑块改变。

A · 已知参数，求均值、ACF 和方差

先检查因果平稳：|0.2| < 1，0.5 + 0.2 < 1，0.2 − 0.5 < 1。常数 c = 0，故 μ = 0。依次计算 ρ(1)、ρ(2)，再求 ρ(3) 与 γ(0)。

B · 已知 ρ(1) = 0.625、ρ(2) = 0.5125，反解参数

先解第二个系数，再代回第一个系数。这里输入的是总体相关，因此恰好还原真实参数。

C · 如果给的是样本相关呢？

例如样本估计为 ρ̂(1) = 0.6、ρ̂(2) = 0.45，使用同一套代数，但答案要戴帽子。它不会自动等于真实的 0.5 和 0.2。

实际写代码解线性方程即可，不必显式求矩阵逆；矩阵奇异时不能照常求解。得到参数估计后还应检查根条件与残差，不能只凭两项相关宣布模型正确。

先读图：每一阶都重新控制中间滞后

k = 1：比较 Yₜ 与 Yₜ₋₁，不控制任何变量。k = 2：比较 Yₜ 与 Yₜ₋₂，先排除 Yₜ₋₁ 的线性预测。k = 3：比较 Yₜ 与 Yₜ₋₃，先排除 Yₜ₋₁、Yₜ₋₂ 的线性预测。

上方方块的横轴是阶数 k，数值是总体 PACF。方块高度表示绝对值，酒红色表示负值；不是一条模拟序列，也不是相关的概率。用下面的对照表区分 ACF 与 PACF。

沿用上一节的 AR(2) 例题

固定 φ₁ = 0.5、φ₂ = 0.2，已求得 ρ(1) = 0.625、ρ(2) = 0.5125。先计算 PACF(1)，再做二阶残差的标准化。

第一阶为 0.625，不是模型参数 φ₁ = 0.5。因为只放一个滞后时，它还包含第二个滞后关联带来的信息；同时放入两个滞后后，末项系数 φ₂,₂ 才等于模型的 φ₂ = 0.2。

“二阶后截尾”不是“第二阶为零”

这里 ACF 的第三阶仍为 0.38125，但 PACF 的第三阶为 0；两者没有矛盾。ACF 保留经过中间时刻传递的线性相关，PACF 则先把中间滞后的线性预测部分剔除。

如果 φ₂ = 0，模型降为 AR(1)，PACF 从第二阶就为零。只有真实阶数恰为 2 时，才说二阶截尾；样本 PACF 的后续柱子通常不精确为零，也不能只凭一个越界点定阶。

更高阶怎样计算：Durbin–Levinson 递推

从 φ₁,₁ = ρ(1) 开始，先求新一阶的末项系数，再更新前面的系数。分母是相对于 γ(0) 标准化的预测误差方差；非退化时为正。

若只给样本相关，用 ρ̂ 替换 ρ，得到系数估计 φ̂ₖ,ⱼ。有限样本估计不会具有完美截尾，仍需结合模型诊断。
