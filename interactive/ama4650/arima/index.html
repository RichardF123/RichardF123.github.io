07.2 / 混合模型

ARIMA：先对增量建模

先问：平稳模型究竟写给谁？

如果某个意外会永久抬高销量水平，把原销量直接放进平稳 ARMA 模型就不合适。课件定义 4.6 换了建模对象：把原序列记作 X_t，先做 d 次普通差分，得到 Y_t。若 Y 服从 ARMA(p,q)，原来的 X 就写作 ARIMA(p,d,q)。

Y_t=(1-B)^d X_t\Phi(B)Y_t=\Theta(B)Z_t

d = 0 时两条序列相同。d = 1 时，Y 描述的是每期增加了多少，而不是当期有多少。

同一组读数，差分到底用了哪几个数？

一个计数器在五个时点依次读作 20、23、25、29、32。切换差分次数，沿着方块读到最后一格，再核对最后一个数怎样算出来。

这是计算示例，不是凭五个点选阶。二阶差分是对增量再差一次，不是拿今天直接减前天：

\nabla^2 X_t=X_t-2X_{t-1}+X_{t-2}

备考：从方程读阶，再还原到原尺度

下面是按定义编的练习题。已知销量增量满足下式，白噪声记为 Z_t。求原销量的模型阶数。

Y_t=0.5Y_{t-1}+Z_t+0.25Z_{t-1}Y_t=(1-B)X_t
先识别平稳部分，再数差分因子

把过去的增量移到左边。左边有一个过去的 Y，右边有一个过去的创新，所以增量是 ARMA(1,1)。代回原销量：

(1-0.5B)Y_t=(1+0.25B)Z_t(1-0.5B)(1-B)X_t=(1+0.25B)Z_t

普通差分因子只有一个。答案是 ARIMA(1,1,1)，不是 ARMA(2,1)：展开后虽有二阶项，但其中一个根等于 1，专门对应差分。剩下的 AR 根是 2，MA 根是 −4。

回到计数器：最后读数 32，最近增量为 3。若已知最后一期创新为 2，且下一期创新的条件均值为零，则下一期增量预测为 0.5 × 3 + 0.25 × 2 = 2；原尺度上的预测是 32 + 2 = 34。

季节差分：去年同月，不是上个月

定义 4.7 另用 S 表示周期。月度数据取 S = 12，普通差分对比上个月，季节差分则对比去年同月。若两者都做一次：

\nabla_{12}X_t=X_t-X_{t-12}Y_t=(1-B^{12})(1-B)X_t

例如差分后的 Y 若是白噪声，且没有其他因子，那么原序列的阶数写作 (0,1,0)\times(0,1,0)_{12}。前一组的 d 数普通差分，后一组的 D 数季节差分；12 是比较的间隔，不是差分次数。
