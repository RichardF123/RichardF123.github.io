AI Infrastructure · Systems Experiment

SpecDec Context Scaling

研究原型

研究问题

在 8GB 消费级 GPU 上，投机解码能否在保持输出分布正确的同时取得真实端到端加速？

关键发现 Draft forward 是主要瓶颈

冻结配置下，0.5B 草稿模型的独立前向开销抵消了接受 token 带来的收益。

方法

块验证、KV Cache 回滚、CUDA Graph、接受率诊断与 draft-free oracle。

环境

RTX 4060 Laptop 8GB，Qwen2.5 target/draft 组合。

  • PyTorch
  • Qwen2.5
  • Speculative Decoding
  • CUDA Graph
  • KV Cache

LLM Application · Hybrid Retrieval

Guizhou Statistical Indicator GraphRAG

可运行项目

应用问题

将用户的口语化查询稳定映射到贵州统计年鉴中的真实指标，并给出可解释的召回依据。

检索结果
89.58%Top-1
100%Recall@5
94.44%MRR@5
方法

别名纠错、关键词与向量混合召回、知识图谱扩展、规则排序和可选 Cross-Encoder 精排。

工程

Flask 服务封装检索流程，NetworkX 管理指标关系，评测脚本输出排序指标。

  • GraphRAG
  • NetworkX
  • Embedding
  • Cross-Encoder
  • Flask

03

NLP · Classification Pipeline

Stock Market Sentiment Classification

完整实验

建模问题

对金融社交文本进行负面、中性、正面三分类，并改善类别之间不均衡的识别效果。

最终模型
0.7467Accuracy
0.7470Macro F1
方法

从 TF-IDF 与 Word2Vec baseline，迭代到 DistilBERT + LoRA，再使用 XGBoost 完成最终分类。

分析

比较训练曲线、类别 F1 与混淆矩阵，并围绕难分类样本调整数据平衡和损失函数。

  • DistilBERT
  • LoRA
  • XGBoost
  • TF-IDF
  • Macro F1
